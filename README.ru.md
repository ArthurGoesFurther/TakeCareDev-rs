# TakeCareDev

[English](README.md) · **Русский** · [中文](README.zh-CN.md)

Пиксельное лицо, которое напоминает делать гимнастику для глаз и вставать со стула. Живёт в трее
(в строке меню на macOS), работает на Windows, macOS и Linux.

Это маленькое нативное приложение на Rust: без браузерного движка внутри, загрузка ~5 МБ, а пока
ждёт — почти не трогает процессор.

## Что умеет

- **Гимнастика для глаз.** Каждые N минут (по умолчанию 20, правило 20-20-20) рядом с курсором
  появляется пиксельное лицо и N секунд (по умолчанию 10) показывает упражнение: влево-вправо,
  вверх-вниз, круги, диагонали, восьмёрка, моргание, зажмуриться, вдаль, близко-далеко, отдых с
  закрытыми глазами. Просто следишь за его зрачками. Окно прозрачное, пропускает клики и не
  забирает фокус — печатать оно не мешает.
- **Встать и походить.** Каждые N минут (по умолчанию 50) — перерыв на N минут (по умолчанию 5):
  карточка с таймером, подсказкой (приседания, лестница, растяжка, вода), «Отложить» и
  «Пропустить».
- **Строгий режим.** Перерыв закрывает экран и прячет кнопки. Экстренный выход — меню в трее.
- **Честный таймер.** По умолчанию таймер перерыва идёт, только пока ты не трогаешь мышь и
  клавиатуру — отсидеться перед экраном перерыва не выйдет.
- **Естественные перерывы.** Если тебя не было дольше N минут (или ноутбук спал), отсчёт
  начинается заново, а не дёргает сразу, как только сел.
- Уведомление за N секунд до перерыва.
- Пауза на 30 мин / 1 ч / 2 ч / до возобновления, статистика за день, автозапуск.
- Можно выбрать упражнения, их порядок, размер лица, угол экрана вместо курсора, подсказку и звук.
- Интерфейс на русском и английском.

Все интервалы и длительности настраиваются: трей → «Настройки…» или повторный запуск приложения.

### Первый запуск

- **macOS:** распакуй и перенеси `TakeCareDev.app` в «Программы». Приложение не подписано
  сертификатом разработчика Apple, поэтому первый запуск заблокируется: правый клик по приложению →
  **Открыть** → **Открыть** (или «Системные настройки» → «Конфиденциальность и безопасность» →
  **Всё равно открыть**). Дальше запускается как обычно. Живёт только в строке меню, иконки в Dock нет.
- **Windows:** распакуй и запусти `takecaredev.exe`. Сборка без подписи, SmartScreen предупредит —
  «Подробнее» → «Выполнить в любом случае».
- **Linux:** распакуй, `chmod +x takecaredev`, запусти. Иконке в трее на GNOME нужно расширение
  AppIndicator (в Ubuntu включено по умолчанию).

## Зачем это

Программист сидит 8–12 часов в день и смотрит в экран в полуметре от лица. От этого тихо ломаются
две вещи: глаза и всё, что ниже пояса.

### Падающее зрение

- **Близорукость — эпидемия.** В 2020 году близоруким был примерно каждый третий человек на Земле;
  прогноз на 2050 год — около половины, почти 5 миллиардов. Долгая работа вблизи и мало времени,
  когда взгляд направлен вдаль, — среди главных факторов риска.
- **Спазм аккомодации.** Чтобы держать фокус на 50 см, цилиарная мышца часами остаётся
  напряжённой. После долгого дня всё вдали плывёт, глаза ноют, болит голова — «компьютерный
  зрительный синдром».
- **Сухой глаз.** Глядя в экран, мы моргаем в 3–4 раза реже обычного (примерно 15–20 раз в минуту
  падает до ~5). Слёзная плёнка высыхает: жжение, покраснение, песок в глазах.
- **Что помогает:** правило 20-20-20, которое рекомендуют офтальмологи, — каждые 20 минут на
  20 секунд смотреть на что-то в ~6 метрах (20 футах), — плюс осознанное моргание и смена фокуса.
  Ровно это лицо и делает.

Честно: гимнастика не вылечит уже имеющуюся близорукость. Она снимает напряжение и сухость и
поддерживает привычку отводить взгляд — то, что в твоих руках.

### Геморрой и сидение

- **Давление.** Когда сидишь, вены анального канала под постоянным давлением, а отток крови из
  малого таза замедляется. Вены растягиваются, «подушки» сползают вниз — это и есть геморрой.
- **Неподвижный кишечник.** Мало движения — медленнее перистальтика, запоры и натуживание, главный
  триггер геморроя. Туда же — долгое сидение в туалете с телефоном.
- **Это очень частая штука.** По разным исследованиям, геморрой есть у ~4–40% взрослых в
  зависимости от методики; просто об этом молчат, пока не заболит.
- **Что помогает:** вставать каждые 45–60 минут и ходить несколько минут. Ходьба восстанавливает
  венозный отток и запускает кишечник. Приседания и лестница из подсказок перерыва — ещё лучше.

Долгое сидение ещё связано с болью в спине и шее, плохим кровообращением в ногах и повышенным
сердечно-сосудистым риском, так что перерыв на прогулку окупается многократно.

TakeCareDev не заменяет врача. Если уже болит или зрение упало — к офтальмологу / проктологу.

## Как устроено

Окна рисуются через [egui](https://egui.rs); трей — StatusNotifierItem по D-Bus
([ksni](https://crates.io/crates/ksni)) на Linux и [tray-icon](https://crates.io/crates/tray-icon)
на Windows и macOS. Лицо и все остальные картинки рисуются кодом — файлов с изображениями нет.

Один бинарник, четыре роли:

| Команда                   | Роль                                                                   |
| ------------------------- | ---------------------------------------------------------------------- |
| `takecaredev`             | демон: трей, таймеры, настройки, статистика; запускает окна ниже       |
| `takecaredev face <json>` | всплывающее лицо (прозрачное, пропускает клики, не забирает фокус)     |
| `takecaredev break ...`   | карточка перерыва или полноэкранная заглушка в строгом режиме          |
| `takecaredev settings`    | окно настроек                                                          |

Окна — отдельные процессы, потому что цикл событий egui/winit можно запустить только один раз на
процесс. С демоном они общаются строками JSON через stdin/stdout (`src/ipc.rs`). На Windows и macOS
главным потоком владеет трей, а демон работает в отдельном потоке.

```
src/
  main.rs         точка входа: выбирает роль
  daemon.rs       связка: события, меню трея, жизненный цикл лица и перерыва
  scheduler.rs    чистая логика таймеров с тестами (часы передаются параметром)
  settings.rs     схема настроек, значения по умолчанию, ограничения
  exercises.rs    упражнения: что лицо делает в каждую секунду
  sprite.rs       лицо, рисуется кодом в любой пиксельный буфер
  i18n.rs         переводы (ru, en)
  store.rs        settings.json и stats.json
  platform.rs     тип сессии, курсор, мониторы, простой (X11 / Mutter / Windows / macOS)
  sound.rs        писк: рендерится в WAV и играется через afplay / paplay / pw-play / aplay
  png.rs          крошечный PNG-кодировщик для иконки приложения
  tray.rs, notify.rs, autostart.rs, ipc.rs
  ui/             face.rs, break_screen.rs, settings.rs
scripts/
  macos-app.sh    собирает TakeCareDev.app (с иконкой, ad-hoc подпись)
```

Настройки и статистика лежат в `~/Library/Application Support/TakeCareDev/` на macOS,
`%APPDATA%\TakeCareDev\` на Windows и `~/.config/TakeCareDev/` на Linux. Формат файлов тот же, что
у прежней Electron-версии TakeCareDev, так что настройки переносятся.

### Сборка

Нужен [Rust](https://rustup.rs).

```bash
cargo run --release                          # демон в трее; первый запуск открывает настройки
cargo test                                   # планировщик, настройки, i18n, спрайт, хранилище
TCDEV_DATA_DIR=/tmp/tc cargo run --release   # отдельный профиль настроек
scripts/macos-app.sh /Applications           # macOS: собрать и установить TakeCareDev.app
```

Пуш тега `v*` собирает все три платформы в GitHub Actions и публикует релиз.

### Особенности платформ

- **macOS:** проверено на Apple Silicon. Курсор берётся из CoreGraphics, простой — из
  `IOHIDSystem`. Мониторы пока не перечисляются: карточка перерыва центрируется на том экране, где
  открылась, а строгий режим закрывает только этот экран.
- **Linux (GNOME, Wayland/XWayland):** проверено. Окна работают через XWayland, чтобы их можно было
  ставить по координатам и находить курсор (на долю секунды экран накрывает прозрачное окно-зонд).
  Простой берётся у Mutter (`org.gnome.Mutter.IdleMonitor` по D-Bus); на других Wayland-композиторах
  функции, завязанные на простой, отключаются. На Wayland лицо появляется рядом с курсором, но
  следовать за ним не может.
- **Windows:** трей, курсор, мониторы, простой, автозапуск и уведомления написаны, но на реальной
  машине ещё не проверялись — отзывы приветствуются.
- Одновременно работает только одна копия (замок — фиксированный локальный порт
  `127.0.0.1:47821`); повторный запуск открывает настройки уже работающей.
